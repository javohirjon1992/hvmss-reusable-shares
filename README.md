# Hash-Verified Multi-Secret Sharing
Local research dashboard for reusable-share multi-secret sharing and dealer-free redistribution. View recorded experiments, compare verification timings, run a local benchmark, and open the accompanying paper.

## Run
From the repository root, run `python app.py` using Python 3. On Windows, double-click `Start_Windows.bat`. The dashboard uses the Python standard library and runs locally.

## Verify
Run `python validation/check_dashboard.py` to exercise the dashboard, paper download, plots and benchmark variants. Measurements started in the dashboard run on the current machine. Recorded samples are in `reproducibility/variant_observations/`. The paper is in `docs/paper.pdf`.

## GitHub
Extract the archive and upload the contents of this directory to the root of the repository.
