# Honest full-transcript and archived implementation comparison

Run `python reproducibility/variant_check.py --output-dir fresh-run` from the project root. The script uses only the Python standard library and imports the two implementation files by explicit path. Their SHA-256 identities are in environment.json.

The functional suite checks both HBV challenge conventions, salted RMSS and a complete honest redistribution of an RMSS batch into plain Shamir shares. Cases cover n=1,4,7, the endpoint and central thresholds, and k=1,4. All 112 component/variant configurations passed and all 880 reconstructions over enumerated threshold subsets returned the intended batch. These finite honest checks establish interoperability of the component interfaces within each version.

Each timing row corresponds to one participant at identity n, or to one RMSS public check. The benchmark passes an already-generated record and invokes the ordinary verifier without caller-supplied challenges. The two versions receive matched test inputs and deterministic fixture randomness. Three warm-ups precede 21 measured calls to each verifier. Within each pair the order of the two versions is shuffled. Measurements include neither generating the sharing nor network transport. The archived HBV verifier reuses its identifier-position map; the specified verifier rebuilds that map at each call. Timing differences therefore describe the complete measured implementations. Each timed call checks its returned verdict.

At n=256, k=1 the median independent HBV verification cost was 0.2033 ms (archived) and 0.2083 ms (specified). The RMSS participant costs were 0.3941 and 0.4092 ms. At n=32, k=64 the independent HBV medians were 0.1924 and 0.4017 ms, and the RMSS participant medians were 1.6776 and 13.4477 ms. The specified independent challenge interface reprocesses the full record separately for each component. The powers mode derives one field challenge before exponentiation. Raw observations, group quartiles and all alternate configurations are available in the adjacent CSV files. Concurrent machine load was uncontrolled; the estimates apply to this run.
